工具副作用边界

入口与生命周期

cmd/server 构造配置和日志，Bootstrap 初始化资源，HTTPHost 安装业务路由并启动服务。排空 HTTP 后停止后台任务，再关闭资源。

cmd/server → internal/service ↗

领域与持久化

Controller 消费小接口，装配层注入 durable.Store。事务和业务不变量在 durable；模型、约束、索引和迁移注册在 table。

internal/app → pkg/durable → internal/table ↗

worker 的合法依赖

外部 worker 导入公开 durable。durable 可以在本模块内部使用 internal/table；表类型没有出现在 worker 的公开接口里。

数据模型与迁移

模型定义在 internal/table，业务事务由 durable.Store 维护。

Agent / AgentVersion

草稿 revision、发布编号与配置；已发布版本不可变。

agent · agent_version ↗

Session / Message

会话归属、有序消息、运行关联和多轮历史。

agent_session · agent_message ↗

Run / Step / Event

冻结快照、状态、checkpoint、租约、epoch、工具步骤和 Outbox。

durable_run · durable_step · durable_event ↗

Evaluation / Trial / Plan

冻结套件、实验状态、试验关联、判分结果和评测方案。

evaluation_experiment / trial / plans ↗

Dataset / DatasetVersion

可编辑数据集、revision 和不可变发布快照。

evaluation_dataset / dataset_version ↗

迁移唯一入口

cmd/cli migrate → Store.Migrate → table.Migrate；在迁移事务中加锁并检查旧数据。API/worker 启动不自动建表。
