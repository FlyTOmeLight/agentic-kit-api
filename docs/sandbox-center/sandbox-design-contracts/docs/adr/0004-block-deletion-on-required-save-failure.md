# 必要保存失败阻止正常销毁

任务结束时，必要检查点或产物保存失败后停止用户执行、保留待保存文件并继续占用配额，直到保存成功或收到明确授权处置。相较于限时重试后自动丢弃，这个选择优先保护尚未交付的修改，代价是故障期间继续消耗资源并需要处理积压。

租约和执行截止时间仍然生效，但空闲回收、硬期限和配额不足不构成删除未保存文件的授权。重试与对账继续已有保存意图，不自行创建业务检查点，也不把旧检查点当作本次必要保存成功。节点故障等不可控丢失仍遵守已定义的恢复等级。

任务拥有者可在业务界面明确确认放弃自己的未保存结果，无需管理员代办；管理员负责有跨用户授权的异常处置。归属与确认委托由可信业务授权验证，普通 Worker 的执行权不包含放弃权。确认绑定当次数据范围及版本，过期确认不能用于新数据；处置只解除对应保存阻塞，不替代进程隔离、在途保存对账与物理清理证据。这样保留了用户对结果的决定权，同时避免 Agent 自动结束任务时误删未交付修改。
