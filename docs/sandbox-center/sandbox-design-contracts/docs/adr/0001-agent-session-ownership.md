# Agent 平台管理 CLI Runner 与 Agent 会话

沙箱服务提供环境、命令、文件、终端和执行记录；agentic-kit 管理 CLI Runner、CLI 版本及参数、结构化事件解析、逻辑会话与恢复。这样 CLI 的变化由 Agent 平台适配，沙箱服务无需理解厂商对话协议；代价是调用方需要通过 Agent 平台完成会话续跑，不能直接调用沙箱 API 恢复 Agent 会话。

沙箱契约不包含 CLI 会话表、Runner SDK 或 CLI 会话到执行的专用映射。恢复时由 Agent 平台核验会话数据和工作区，再用通用执行 API 创建新的执行尝试并保存关联；沙箱保存的文件检查点只声明路径和文件覆盖范围，不证明 CLI 会话可恢复。终端、浏览器和预览的访问会话仍归沙箱服务管理。
