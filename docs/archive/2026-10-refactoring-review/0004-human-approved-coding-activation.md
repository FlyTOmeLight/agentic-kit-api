# 复用代码验证记录，启用须经人工确认

状态：历史评审决策。已移出当前通用Agent框架重构范围，由独立评测/场景任务承接；不作为本轮实施规范。

2026-10-15，设计评审确认：企业共享 Coding 候选在项目 A 的通过验证记录可以用于项目 B，也允许选择在 B 再验证；项目 B 的启用必须经过人工明确确认。验证通过、后台协调和可信服务身份都不能代替这次人工决定。记录验证来源与目标项目，区分源项目已经验证与目标项目尚未验证，既支持候选复用，也保留每次启用的人工责任和可追溯来源；项目私有候选的原项目限制不变。

跨项目复用时，确认人必须同时具有源验证记录读取权限、候选读取权限和目标项目管理权限。无需引入跨项目分享验证摘要的第二套授权路径，也不能因候选企业共享而开放源项目的私有验证内容。

最终生效前再次检查确认人的上述权限；已撤权则停止生效、使审批失效，并要求符合权限的人重新确认。权限依赖不可用只阻止本次操作，不放行或误判为永久撤权；该规则针对尚未生效的审批。

配置生效后属于项目，原确认人的权限变化不自动停用它；当前管理员决定停用或回退，实际执行者的资源权限继续按当前身份校验。这样审批人在职状态不会成为已生效项目配置的持续运行依赖。
