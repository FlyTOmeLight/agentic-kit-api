# 评测不得改变线上Agent和Memory

状态：历史评审决策。已移出当前通用Agent框架重构范围，由独立评测/场景任务承接；不作为本轮实施规范。

2026-10-15，设计评审明确：评测与线上业务状态隔离，不能更新线上Memory、Agent配置、项目生效绑定或线上会话历史，也不能因测试通过自动学习、晋升或启用。实验运行、上下文、工具环境和验证结果归实验自身，评测资源设置独立并发与预算；共享存储与执行协议不意味着允许共享可变业务状态。

评测默认关闭Memory，显式启用时可以复制授权的明确版本作为实验只读输入，创建实验时固定材料及策略，不跟随线上纠正或更新。这样可以检验实际记忆的作用而不污染线上；普通候选比较要求相同记忆模式和材料，不把输入差异归因为Agent版本差异。
